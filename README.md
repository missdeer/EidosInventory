# Eidos 工作室库存台账 Demo

基于 Go、GORM、SQLite 和 Bootstrap 的响应式网页应用。首次启动会建立数据库，并录入 `库存台账_示例.xlsx` 第二个工作表中已有的 9 件资产；示例表仍作为原始参考，不会被修改。

## 启动

需要 Go 1.26，无需 C 编译器或 CGO。在项目目录运行：

```powershell
go run .
```

浏览器打开 <http://127.0.0.1:18080>。SQLite 数据库及上传照片保存在 `data/`，重启不会清空。首次启动生成以下演示账号：

| 账号 | 密码 | 权限 |
| --- | --- | --- |
| `viewer` | `viewer1234` | 查看和检索资产 |
| `editor` | `editor1234` | 查看、新增、编辑资产 |
| `admin` | `admin1234` | 读写资产、创建账号、调整权限及重设密码 |

演示账号使用公开初始密码。若要在局域网或公网开放，请先用管理员账号修改这些密码，并在 HTTPS 反向代理后运行。默认只监听本机；局域网演示可设置 `ADDR=0.0.0.0:8080`，也可用 `DATA_DIR` 改变数据目录。

## 主要规则

- 一条记录代表一件实物；“停用”记录保留，编号不复用。
- 标签格式为 `类别 + 组别 + 适用 + 款式编号 - 规格码 - 单件序号`。设计序号由录入人选择，单件序号自动取该款式和规格的下一个号码，跨颜色共用。
- 鞋类填写鞋型、鞋帮、穿脱结构；同款、同色、同尺码的鞋最多 4 双处于“在库”状态。
- 台账可切换“精简”和“完整台账”视图；完整视图按示例表第 6 行展示全部 20 列。
- 编辑页面可修改照片、类别、名称、组别、适用、颜色、尺码/规格、搜索关键词、存放位置、状态、鞋型、鞋帮、穿脱结构、设计序号和单件序号。标签编号、款式编号、规格码、同款同色同尺码在库及校验由系统计算并在编辑页显示。修改编号组成字段会生成新标签编号；旧编号保留且不会复用，需要重新贴标。
- 颜色、尺码/规格、存放位置使用下拉选项，预置常见颜色、鞋码、童装尺码、S/M/L/XL、均码和 A–E 架位；升级时自动补入已有资产的自定义值。存放位置可以留空。
- 管理员可在“可选值管理”新增、改名或停用九组选项。原六组编号字段保留不可变的一位编码；颜色、尺码/规格、位置无需填写编码。改名同步到已有资产，已被资产使用的选项不能停用。已使用尺码不能改名为另一规格，请新增规格后从资产编辑页修改，以重新生成标签并保留旧号。
- 搜索范围包括编号、名称、颜色、关键词和位置。照片支持 JPEG、PNG、WebP，最大 5 MB。
- 新增和编辑资产时可手动填写“同款同色同尺码在库”数量，并选择“校验”为正常、异常或待校验；数量留空、校验选择自动时使用系统计算结果。手动值按每条资产记录保存并显示在完整台账和详情中，不增删实物记录，鞋类在库上限仍按实际记录判断。
- 在台账中点击资产名称或“查看详情”，可浏览照片、所有台账字段、编号组成、同规格在库数量、校验结果及记录时间；读写账号可从详情页进入编辑。

示例表第 7 行的“魔术贴板鞋”鞋型为“靴子”，标签为 `SKM41101-28-01`。Demo 保留原表数据，不擅自改成“运动/板鞋”。
